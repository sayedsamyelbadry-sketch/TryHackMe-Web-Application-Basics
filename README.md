## 📝 Overview

**Web Application Basics** is an introductory TryHackMe room designed to build a solid understanding of how modern web applications function. The room focuses on the client-server communication model, HTTP protocol fundamentals, authentication mechanisms, and the core concepts required before studying web application security.

---

## 🎯 Objectives

- Understand the architecture of web applications.
- Learn how browsers communicate with web servers.
- Analyze HTTP requests and responses.
- Identify the purpose of HTTP methods and status codes.
- Understand cookies, sessions, and authentication.
- Build the foundation required for Web Application Penetration Testing.

## 🛣️ Methodology

### 1. Understanding Web Communication
- Client–Server Architecture
- DNS Resolution
- HTTP vs HTTPS
- Request/Response Lifecycle

### 2. HTTP Analysis
- **HTTP Methods:** `GET`, `POST`, `PUT`, `DELETE`
- **HTTP Headers:** Request & Response Headers
- **Status Codes:** `2xx` (Success), `3xx` (Redirection), `4xx` (Client Error), `5xx` (Server Error)

### 3. Authentication Concepts
- Cookies & Session Management
- Authentication Tokens
- Session Life-cycle & Security

### 4. Web Security Fundamentals
- Security Headers (`X-Frame-Options`, `Content-Security-Policy`, etc.)
- Common Misconfigurations
- Importance of Secure Authentication Mechanisms
- Introduction to Web Security Best Practices

## 💡 Key Concepts Learned

- How web applications process user requests end-to-end.
- The importance of HTTP methods and HTTP response codes.
- How cookies and sessions maintain authenticated states.
- Why security headers improve web application security defense-in-depth.
- The necessity of mastering fundamentals before exploring vulnerabilities such as:
  - **SQL Injection (SQLi)**
  - **Cross-Site Scripting (XSS)**
  - **Server-Side Request Forgery (SSRF)**
  - **Insecure Direct Object References (IDOR)**
  - **Broken Access Control**
